# 🐍 Enhanced Snake Game 🕹️

Welcome to the **Enhanced Snake Game**, a modern twist on the classic Snake game built with Python and Pygame! 🎮 This project features a sleek interface, customizable game speeds, high score tracking, and smooth controls for an addictive gaming experience. 🚀

## 🌟 Features

- **Responsive Controls** 🕹️: Use `WASD` keys to navigate the snake with precision.
- **Customizable Speed** ⚡: Choose from multiple speed levels (5 to 30) to match your skill level.
- **High Score System** 🏆: Save and display the top 10 scores with details like score, speed, and date.
- **Polished UI** ✨: Enjoy a clean main menu, instructions, and game-over screens with button interactions.
- **Visual Effects** 🎨: Smooth snake movement, glowing food, and rounded edges for a modern look.
- **Game States** 🔄: Pause, restart, or quit anytime with intuitive controls (`P`, `R`, `Q`).
- **Cross-Platform** 🌐: Runs on any system with Python and Pygame installed.

## 🛠️ Installation

Get started in just a few steps! Follow these instructions to set up the game on your machine.

### Prerequisites
- 🐍 Python 3.6 or higher
- 🎮 Pygame library (`pip install pygame`)

### Steps
1. **Clone the Repository** 📂
   ```bash
   git clone https://github.com/your-username/enhanced-snake-game.git
   cd enhanced-snake-game
   ```

2. **Install Dependencies** ⚙️
   ```bash
   pip install pygame
   ```

3. **Run the Game** 🎉
   ```bash
   python main.py
   ```

## 🎮 How to Play

1. Launch the game and navigate the **Main Menu** using your mouse. 🖱️
2. Choose **Play Game** to start, **Set Speed** to adjust difficulty, or **Instructions** for controls. ℹ️
3. Use **WASD** keys to move the snake and eat the red food to grow. 🍎
4. Avoid hitting the walls or your own tail! 🚫
5. Press:
   - `P` to pause/resume ⏸️
   - `R` to restart 🔄
   - `Q` to return to the menu 📋
6. Aim for a high score and get your name on the leaderboard! 🏅
